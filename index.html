      SwitchProof

      ISO 8583 · Oracle FLEXCUBE ATM & POS switch

      Functional, UAT and load testing for your card switch.

      Send real ISO 8583 traffic to the switch, check every response against what you expect, and keep evidence of each result for sign‑off.

      Functional
      Withdrawal, balance, purchase and settlement, transfer, refund, deposit and reversal, driven by CSV or Excel data.
      UAT
      Test-case library and scenario chains with expected response codes, pass/fail, printable evidence and your bank's test-sheet format.
      Load
      Hundreds of concurrent transactions with live throughput, latency and response-code breakdown.
      Environments
      UAT and production switches side by side, each with its own acquirer, terminal, card and test accounts.
      Data residency
      Messages are sent by a Windows agent inside your network. Switch addresses, accounts and evidence never reach this site.

      For use with the Oracle FLEXCUBE ATM/POS switch. Not affiliated with Oracle; Oracle and FLEXCUBE are trademarks of Oracle Corporation.

      Set up

      Connect your agent

      The console runs in this browser. Messages to your switch are sent by SwitchProof for Windows on a PC inside your network.

      Already installed SwitchProof? Versions before 1.4 can't connect to switchproof.online. Download and run the installer below: it closes the old version, updates it and keeps your targets, test cases and results.

      1. Download SwitchProof for Windows On a PC that can reach your switch (bank network or VPN). About 35 MB, Java included, no admin rights needed.
      2. Run the installer If Windows shows Windows protected your PC, choose More info, then Run anyway.
      3. SwitchProof starts by itself When the installer finishes (next time, from the Start menu or desktop). This page connects automatically. Keep the SwitchProof window open while you test.
      4. Add your switch Under Target, top right: the switch IP address and port.

      Bank database

      For each RRN, SwitchProof reads the switch log, the accounting entries and the amount blocks, and checks what the transaction really did to the money. It only reads (SELECT): use a read-only database user. These details stay on this PC.
