2. What SwitchProof is

SwitchProof is a testing tool for card switches that use ISO 8583 messages. It has two parts:

  • The console: the website at switchproof.online, where you sign in and work.
  • SwitchProof for Windows (the "agent"): a program you install on a PC inside your network. It sends the test messages to the switches you set up and, if you choose, reads the bank database you set up to check what each transaction did.

The console runs in your browser and talks directly to the agent on your PC.
